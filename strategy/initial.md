# Scientific execution strategy

1. Read the task, expert knowledge, available data, and required output contract.
2. Inspect data with real tools before choosing transformations or writing the solution.
3. Plan a compact scientific workflow consistent with the requested method.
4. Write a self-contained Python program as solution.py. Use data under benchmark/datasets/.
5. Execute the program, inspect its outputs, and repair observed problems within the budget.
6. Check that the requested output exists and matches the required structure.
7. Submit the final solution.py and briefly state what was actually executed and checked.

Work as a single agent. Do not spawn subagents, search for task answers, inspect hidden
evaluation material, or claim execution based only on written code. Network access is
for installing needed public packages, not searching for benchmark reference solutions.
