# AGH-RSI

通过 AGH 执行科研任务，并根据运行反馈改进通用执行策略。

内层完成任务规划、数据探索、程序编写、实际执行和自检；外层依据 ScienceAgentBench 开发集的独立评测与失败轨迹，提出策略修改，重测后接受或回退。

第一版的外层仅修改通用策略文件。AGH、模型、数据和评价器的身份需明确记录；任务划分、预算和接受规则在实验前冻结。

## 当前状态

项目初始化完成，尚未实现任务运行器或启动 benchmark 实验。已有接入背景、证据位置与评测边界见 [HANDOFF.md](HANDOFF.md)。交接文档中的环境状态是历史记录，需要重新核验。

## 目录

- `config/`：可复现运行配置，不存储凭据。
- `src/`：任务执行、独立评价与策略改进代码。
- `strategy/`：通用策略及其版本。
- `tasks/`：任务划分与身份清单。
- `docs/`：环境检查和开发说明。
- `runs/`：本地运行产物，默认不提交。
