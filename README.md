# FeedVerse · 推荐平行世界

由 AGH 驱动的推荐机制实验平台。用户通过自然语言提出目标，AGH 调用我们开发的工具，在可视化的平行世界中设计、执行和比较实验，展示不同推荐规则的收益与代价。

## 产品方向

首个场景：让新创作者获得更多曝光，同时保持用户满意度。

- **模拟引擎**：用可解释、可复现的代码模拟用户、创作者、内容和推荐反馈。
- **AGH 工具接口**：创建世界、查询状态、分叉对照、设置推荐策略、推进模拟、比较结果和追踪个体。
- **可视化界面**：并排展示两个世界、播放与回看时间轴、查看个体经历和指标，并呈现真实工具调用记录。

AGH 负责规划、操作、反馈调整和验证；引擎负责计算，界面负责展示。AGH 不能修改行为模型或指标定义来让实验显得成功。模拟结果仅表示给定假设下的机制效果。
