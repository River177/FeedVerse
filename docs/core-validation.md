## AGH 实际执行

真实会话 `agnes:local:local-dev:cli:workspace:0773b647b3b0ae69`，固定 Astra deployment。AGH 自行生成了三个不同模型源码，通过 MCP 真正调用训练、读取状态、重载评价和比较。所有模型均有五个 epoch 的真实训练日志及独立 checkpoint；没有额外科研候选或重训。

content_gru 引入文本内容投影与 GRU/平均池化；attention_content 使用候选条件的历史注意力和时间位置衰减；hybrid_content 加入短历史 GRU 与语义残差。第三个模型未超过第二个模型的选定指标，保留其源码和结果。差异不能归因于单个组件。

## 故障与边界验收

首次 MCP 启用因 AGH 未显式允许本地 loopback HTTP 而失败。通过官方配置允许本地连接后恢复，原始失败回执保留。TRAPI 有 429 回执；SDK 有界重试在同一会话恢复，未登录或更换模型。三个科研候选没有训练/评分错误，不能把测试夹具故障冒充真实科研失败。所有训练日志有 OpenMP 临时文件告警，训练与重载均成功。

核心集成测试覆盖取消、manager 被 SIGKILL 后识别中断并按身份恢复、完成训练不重复启动、每 attempt 独立产物、非有限评分失败回执与同候选修复、源码与 checkpoint 身份变化拒绝、候选数量限制、选择冻结和保留访问门禁。其余测试覆盖标签筛选/对应、空历史/未知文章、非法分数/重复候选、缺失不填零、独立指标。真实四个模型均通过未知文章与空历史评分、两次独立重载一致性检查。MCP stdio 协议与实际排名/曝光比较也通过。

macOS Seatbelt 实测阻止候选越界读写和网络；AGH 自身策略实测阻止保留标签读取和项目源码写入。评分进程输入无标签。验证与保留用户无交集，原件和冻结输出的哈希均通过。管理器的 attempt 隔离与失败修复在最后的独立小夹具中补充验证，没有重跑或改写四个科研模型。

核心 Python 测试 7 项、原有网页测试 4 项与网页生产构建通过。前端源码保持原样。AGH daemon 已停止。

## 结论限制与产物

本轮证明真实代码修改、训练和独立评分已接通，并在这个固定子集上改善了轻量 ID 基线。只有一个 seed、一次探索；基线对未知文章只有统一表示，而候选获得可学习内容表示，符合冷启动任务，但不能证明 AGH 比人工工程师更优秀，也不是完整 MIND 官方成绩或普遍自我改进结论。第二/第三候选的微小差别不作显著性声明。
