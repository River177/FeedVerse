# FeedVerse 交互原型验收

## 交付范围

本地 React + TypeScript 应用，Vite 启动和构建。无服务器调用、无 AGH 推理、无付费模型调用。图形采用 SVG，DM Sans 字体本地打包；中文使用操作系统字体。所有星图和指标来自 `feedverse-sim/0.1`，没有写死的展示成绩。

## 演示路线

1. 在默认双世界中拖动时间轴，观察相同创作者的曝光变化。
2. 点击「追踪沿途有光」，比较曝光曲线、独立用户和点击。
3. 点击「开始探索」，观看演示控制器调用本地工具，比较两组策略。
4. 展开记录中的输入与输出，核对参数和结果。
5. 查看种子 79 的复验结果；未达标也会明确显示。
6. 进入实验设置修改规则或目标。到实验档案打开先前方案，或导出 JSON 留存。

## 已验证

- 生产构建与 TypeScript 检查通过。
- 四组引擎测试通过：确定性复现和分支隔离、曝光与触达守恒、基于指标的目标判定、非法输入拒绝。
- 浏览器内跑通完整探索；默认种子 42、60 轮得到新作者曝光约 23.0%，满意度相对基线约 -1.2 分。数字是本次参数下的结果，不是固定断言。
- 播放推进、暂停、时间轴端点操作、手动策略修改和非法种子提示正常。
- 创作者详情联动正常；移动端创作者搜索可用。
- JSON 下载后独立读取验证：每个世界 61 帧，每世界最终 28,800 次曝光，包含参数与工具事件。
- 桌面 1440px 和手机 390px 断点检查，无横向页面溢出；浏览器未发现应用错误。

## 下一步接口

已独立实现 `createWorld`、`forkWorld`、`simulate`、`compareWorlds`。当前界面中 `inspect_world` 与 `trace_entity` 直接读取已计算状态；`set_policy` 选择模拟参数。真实 AGH 接入时应提供正式工具服务，保留工具执行事件并替换预设控制流程，继续禁止 Agent 修改用户行为模型和指标定义。
