# FeedVerse 交互原型验收

## 交付范围

本地 React + TypeScript 应用，Vite 启动和构建。无服务器调用、无 AGH 推理、无付费模型调用。图形采用 SVG，DM Sans 字体本地打包；中文使用操作系统字体。所有分布图和指标来自 `feedverse-sim/0.1`，没有写死的展示成绩。

## 演示路线

1. 在默认双世界中拖动时间轴，观察相同创作者的曝光变化。
2. 点击曝光变化明细中的创作者，比较曝光曲线、独立用户和点击。
3. 点击「运行演示实验」，观看演示控制器调用本地工具，比较两组策略。
4. 展开记录中的输入与输出，核对参数和结果。
5. 查看种子 79 的复验结果；未达标也会明确显示。
6. 进入实验设置修改规则或目标。到实验档案打开先前方案，或导出 JSON 留存。

## 已验证

- 生产构建与 TypeScript 检查通过。
- 四组引擎测试通过：确定性复现和分支隔离、曝光与触达守恒、基于指标的目标判定、非法输入拒绝。
- 浏览器内跑通完整探索；默认种子 42、60 轮得到新作者曝光约 23.0%，模拟反馈得分相对基线约 -1.2 分。数字是本次参数下的结果，不是固定断言。
- 播放推进、暂停、时间轴端点操作、手动策略修改和非法种子提示正常。
- 创作者详情联动正常；移动端创作者搜索可用。
- JSON 下载后独立读取验证：每个世界 61 帧，每世界最终 28,800 次曝光，包含参数与工具事件。
- 桌面 1440px 和手机 390px 断点检查，无横向页面溢出；浏览器未发现应用错误。

## 下一步接口

已独立实现 `createWorld`、`forkWorld`、`simulate`、`compareWorlds`。当前界面中 `inspect_world` 与 `trace_entity` 直接读取已计算状态；`set_policy` 选择模拟参数。真实 AGH 接入时应提供正式工具服务，保留工具执行事件并替换预设控制流程，继续禁止 Agent 修改用户行为模型和指标定义。

## 前端改版

页面改为中性色的实验工作台，取消宣传式标题、紫色渐变、星空轨道、发光效果、虚构个人资料与装饰性大圆角。用实验配置、数据条件、排序规则和执行记录组织内容。

新增曝光变化明细，可筛选新作者或全部创作者，按变化幅度、曝光增加或曝光减少排序，并打开同一对象的对照详情。排序规则弹窗展示当前公式、参数和未训练的状态。此改版没有接入真实推荐模型训练或 AGH。

改版后重新验证了桌面和手机布局、明细排序与详情联动、排序规则说明和演示执行。手机明细表采用局部横向滚动，页面没有横向溢出。引擎测试仍通过；界面颜色与文字变化不改变推荐计算规则。
